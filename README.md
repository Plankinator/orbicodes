All the code in this repo is my own work and was not written using AI.

This is my personal project where I'm reviewing the fundamentals of Orbital Mechanics and writing scripts to determine and propagate orbits.

My goal is to build up to visualizing interplanetary trajectories subject to realistic perturbations using planetary ephemeris data, including low-thrust burn optimization.

At the moment I'm starting with propagating idealized Earth-centric orbits, and will soon be incorporating various perturbations, then moving on to the restricted three body problem for cislunar trajectories.
